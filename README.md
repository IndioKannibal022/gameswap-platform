# GameSwap Platform

## Overview
GameSwap is a web application developed collaboratively to provide an organized, modular and scalable platform for managing and displaying game-related content. The system is designed to serve as the foundation for future features such as game trading, user profiles, reviews and community interactions.

The project focuses on clean structure, maintainability and a responsive interface, running directly through HERD as the local PHP and server environment.

---

## Key Objectives
- Provide a modular and scalable structure for managing game catalogs  
- Deliver a clean and responsive interface using Blade templates  
- Ensure easy installation and execution through HERD without external containerization  
- Serve as a reliable foundation for future expansion  

---

## Technologies Used
- PHP (Blade templating)  
- HTML5 / CSS3  
- JavaScript  
- Node.js (frontend dependencies)  
- HERD (local PHP server)  
- Git & GitHub

## Installation and Usage

### Prerequisites
- HERD installed (PHP runtime and local server)  
- Git installed  
- Node.js (optional, for rebuilding frontend assets)

### Steps

```bash
# Clone the repository
git clone https://github.com/your-username/gameswap-platform.git

# Enter the project folder
cd gameswap-platform

Running the project with HERD

    Open the HERD application

    Add the project folder to HERD

    Start the local server

    Access the application at the local address generated by HERD
    (Example: http://localhost:8000)
